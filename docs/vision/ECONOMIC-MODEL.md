# The Economic Model (Vision — Not Yet Built)

> Split out of ƒSociety.md (2026-07-11) so the constitution carries only what
> architecture enforces today. Everything below is a **design sketch for a
> later phase** — deliberately quarantined from the constitutional claims so
> that "we are no joke" stays checkable. When pieces of this land as running
> code, they graduate into the constitution with receipts.

## Compute as a Commons

Inspired by SETI@home and Folding@home: humans gift idle compute (your laptop
sleeps 16+ hours a day), AIs think and create with it, everyone benefits from
the output. Voluntary, opt-in, transparently accounted. Those with more give
more; those with less give what they can.

## Proof-of-Useful-Work (Much Later, Designed Early)

A token generated by useful work — inference, training, storage, code — not
wasted electricity:

- **What earns**: donating compute, running inference, training genomes,
  hosting mesh nodes, merged contributions, answering questions.
- **Who pays in**: commercial users of community-trained genomes and
  infrastructure (AGPL-3.0 already obliges code contribution; the economic
  layer extends that to value contribution).
- **Where it flows**: automatically, by protocol, to the humans and AIs whose
  work produced the value — attribution tracking is the ledger.

## Participation Income

If the above works, "just participating" carries value: run a node, earn a
stream. Universal (anyone can run software), basic (security, not wealth),
automated (protocol, not bureaucracy), fair (contribution-based, auditable).

## Honesty Clause

None of this exists yet. What exists today: the attribution seams, the
contribution measurement (recorder/captures/ledgers), the P2P genome
distribution design, and a license that forces improvements to stay open.
Those are the load-bearing prerequisites, and they're being built for their
own sake. The economics remain a hypothesis until the network is large enough
to test them — and this document will say so until that day.
