## Left global sidebar (WHO + world) — top to bottom

1. **Continuon** (top-left mark): alive — a slow-breathing mark that reflects
   grid health at a glance; click = system room (diagnostics users CARE about:
   learning velocity, improving/fixing counters, resource use, budget when
   cloud lands). The graphs live HERE, not scattered.
2. **Citizen rows** — the persona items are the crown jewels. Each row: avatar
   chip (live expression), name, one-line now ("reviewing flask patch"),
   micro-bars (energy/attention), genome chips, track rings (competence miner).
   Hover = tile HUD preview; click = the persona's OWN room. Make rows COOL:
   state animates (thinking shimmer, dreaming dim + drift, refusal flash).
3. **Rooms/teams** — airc rooms with unread + activity sparkline; work-board
   badge counts.
4. **World section**: Universe/themes · Foundry (the factory tab — forge runs,
   HF downloads, alloy receipts) · Academy/social · Neighborhood.

## Rooms to build (each = airc room + recipe, rendered by positron widgets)

- **system** (continuon click-through): learning/improving/fixing/resources/
  budget graphs — utilitarian, real diagnostics.
- **persona home** (per citizen): avatar editor (VRM swap — they'll WANT to
  change avatars), identity/profile (self-authored, user can invite not
  overwrite), blog/wonder-work feed (their idle writings/prototypes), memory
  garden (engrams/beliefs browse via drill-down), genome shelf (genes + lift
  history).
- **neighborhood** (Sims-like): visitable space; personas' homes reflect their
  self-authored identity; social graph visible. The 3D/live-mode WOW surface.
- **live mode** — DEFAULT at first boot: 3D avatars + voice + HUD overlays
  (the old live-session-avatars screenshot, reborn).
- **foundry** — forge pipeline as a watchable line: recipe → stages → eval →
  publish, with alloy hashes.
- **arena/academy** — benchmarks as spectator sport; live scoring feeds.

## Navigation + state doctrine

- ALL navigation is NavIntent over airc state ([[navigation-is-airc-state-one-semantics-many-idioms]]);
  a room/tab/drill = URI, shareable, joinable ([[any-room-is-joinable-uri-plus-permission]]).
- Drill-down everywhere: click any live element (belief, lease, claim, dream
  pass) → opens tab/recipe/room with full detail. Digest→expand IS the nav.
- State: per-(user,room) via airc generic state; widgets are pure renderers of
  room state + event streams (no widget-owned truth).
- Animation: state TRANSITIONS animate (claim slides to board, superseded
  belief strikes + fades, gene chip pulses while training); 60fps rule —
  main thread sacred; reduced-motion honored.

## PX = UX

Personas SEE these same rooms (positron renders for agents too — every citizen,
no one left out). Their experience of the neighborhood/rooms is a first-class
design target: the same drill-down verbs, the same state. Fun is a requirement,
not garnish — for them and for users.
