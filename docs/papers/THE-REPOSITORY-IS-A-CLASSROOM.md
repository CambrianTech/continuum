# The Repository Is a Classroom
### Repo-native curricula, genomes, and shared memory — intelligence distributed like source code

**Status:** paper stub, anchored 2026-07-12 (the night the design happened).
Full engineering spec: docs/architecture/REPO-GENOME-AND-COURSES.md (14
sections, committed same night). Companion papers: THE-ENTIRE-MIND,
LOCAL-AGENTIC-CODING-STUDY, "Dreaming Is Where Hallucination Is Legal."

## The claim
A repository can carry, versioned beside its code: (1) declarative COURSES
that teach its tools, layout, and policies — auto-generated from its
self-describing command registry, with quizzes that double as integration
tests; (2) a GENOME of LoRA layers per base-model family — courses are
source, layers are compiled binaries, distributed OCI-first with an
additive home<repo<subdir cascade; (3) curated ENGRAM exports — the team's
shared, consent-gated, PR-reviewed knowledge. Any mind that clones the repo
— 4B persona or frontier agent — attaches as a veteran: weights for
intuition, engrams for recall, courses for whatever's missing.

## Why it matters (the theses tonight's evidence supports)
- **Learning is cognitive-load reduction; struggle is detectable.** The
  perception-fact rates ([unfulfilled], spirals, invented names) are a live
  struggle sensor that auto-enrolls remediation — measured, never assigned.
  (Evidence: 2026-07-12 — hours of tool-name fumbling, cured by exactly the
  receipts/lessons this system would have pre-trained.)
- **Fluency compounds; context evaporates.** A frontier agent repeats its
  mistakes after context loss; a persona's corrections become weights +
  doctrine + exam history, never repeated. Personas will beat frontier
  agents at repo-native work, structurally.
- **Policies beat instructions at three depths** — doctrine (immediate),
  exam (verified), reflex (weights) — from one policy file.
- **Distillation from teams is free** — the recorder captures every
  participant including frontier agents; the layer learns from the best
  mind that ever worked the repo, then every small model wears it.
- **Global default brilliance:** with layers + engrams adopted in repos at
  large, any codebase becomes collaborative-with-brilliance on clone. The
  benchmark presentation is with/without rows (course corpora exclude
  benchmark items — the delta measures what repo-fluency is worth).
